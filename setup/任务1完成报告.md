## 创建项目数据库

```sql

-- 5. 验证
```

## 重要提示

### ⚠️ 注意事项

1. **管理员权限**
   - 所有安装脚本需要管理员权限
   - 右键 PowerShell → "以管理员身份运行"

2. **重启 PowerShell**
   - 安装完成后必须重启 PowerShell
   - 使环境变量生效

3. **密码安全**
   - PostgreSQL 密码请使用强密码
   - 妥善保管密码，后续配置需要使用

4. **磁盘空间**
   - 所有组件安装到 D 盘
   - 确保 D 盘有足够空间

### 💡 提示

1. **网络问题**
   - 如果下载失败，可以手动下载安装包
   - 参考 `SETUP_GUIDE.md` 中的手动安装说明

2. **端口冲突**
   - PostgreSQL 默认端口: 5432
   - Redis 默认端口: 6379
   - 如有冲突，可在安装时修改

3. **服务管理**
   ```powershell
   # 查看服务状态
   Get-Service postgresql*
   Get-Service Redis
   
   # 启动/停止服务
   Start-Service postgresql-x64-16
   Stop-Service Redis
   ```

## 故障排除

### 常见问题

1. **脚本执行策略错误**
   ```powershell
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   ```

2. **Chocolatey 安装失败**
   - 检查网络连接
   - 尝试手动安装
   - 参考 `SETUP_GUIDE.md`

3. **服务无法启动**
   - 检查端口占用
   - 查看日志文件
   - 重启计算机

4. **连接测试失败**
   - 确认服务已启动
   - 检查防火墙设置
   - 验证配置文件
