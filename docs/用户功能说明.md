# Anx Showtime 用户功能说明

## 📋 文档说明

本文档面向非技术人员，介绍 Anx Showtime 工时智能工作台的各项功能。

**系统定位**：Anx Showtime 是一个工时统计与项目进度分析系统，帮助团队追踪工时填报、审批进度和项目节点执行情况。

**访问方式**：通过浏览器访问 Hugging Face Space 地址即可使用。

---

## 🎯 核心功能概览

系统提供 5 个主要功能模块：

| 模块 | 功能 | 适用人群 |
|------|------|----------|
| **仪表盘** | 查看总工时、项目分布、工时走势等统计信息 | 所有用户 |
| **项目分析** | 监控项目节点进度和区间工时分布 | 项目经理、技术负责人 |
| **定制化数据** | 导出每项目工时数据 | 数据分析师、财务人员 |
| **完整填报率** | 查看员工工时填报差异 | 部门主管、HR |
| **审批完成率** | 查看待审批工时汇总 | 审批人、项目经理 |

---

## 📊 1. 仪表盘 - 工时统计总览

### 功能介绍
仪表盘是系统的首页，提供工时数据的全局视图。

### 主要内容

#### 1.1 统计卡片
- **总工时**：当前筛选周期内所有项目的总工时（仅统计已审批完成的记录）
- **项目平均**：每个项目的平均工时
- **数据点**：工时记录条数

#### 1.2 工时走势图
- 显示工时随时间的变化趋势
- 支持按周/月/季度查看
- 多项目对比展示

#### 1.3 项目分布
- 显示各项目的工时占比
- 以饼图形式展示

#### 1.4 活跃热力图
- 显示每天的工时填报情况
- 颜色深浅表示工时多少

### 使用方法

#### 时间筛选
- **年份**：选择年份（必选）
- **月份**：选择月份（可选）
- **周**：选择周（可选）
- **粒度切换**：在周/月/季度之间切换

#### 筛选器
- **部门筛选**：多选部门，查看特定部门的工时
- **项目筛选**：多选项目，查看特定项目的工时

#### 导出功能
- 点击"导出 Excel"按钮可导出当前视图的数据

## 📈 2. 项目分析 - 项目节点进度监控

### 功能介绍
监控项目各节点的计划与实际执行情况，查看区间工时分布。

### 主要内容

#### 2.1 项目进度卡片
每个项目显示：
- **项目名称**：项目标识
- **BU**：业务单元
- **状态**：项目当前状态
- **计划周期**：计划总周期（天）
- **实际周期**：实际总周期（天）
- **变化天数**：计划与实际的差异

#### 2.2 节点时间线图
- **计划日期**：蓝色圆点表示
- **实际日期**：蓝色实心圆点表示
- **未到达**：菱形空心点表示
- **Delta**：显示计划与实际的差异天数

#### 2.3 区间工时堆积图
- 显示相邻两个节点之间的部门工时分布
- 横轴：工时
- 纵轴：节点区间
- 不同颜色代表不同部门

### 使用方法

#### 上传项目进度表
1. 点击"上传项目进度 Excel"按钮
2. 选择包含项目进度数据的 Excel 文件
3. 系统会自动解析并替换现有数据

**Excel 文件要求**：
- 工作表名称必须为：`Schedule`
- 第 3 行为表头
- 每个项目占 3 行：MRD plan、Actual/Outlook、Delta
- 必须包含所有 milestone 列（Pre-Gate0 到 RTP）

#### 项目筛选
- 点击"选择项目"按钮
- 多选需要查看的项目
- 支持"全选"和"清空"

#### 图表模式切换
- **月度工时**：显示每月的部门工时堆积
- **节点工时占比**：显示节点区间的部门工时分布

## 📤 3. 定制化数据 - 数据导出

### 功能介绍
导出每项目工时的宽表数据，用于进一步分析。

### 主要内容

#### 3.1 导出统计
- **项目数**：导出的项目数量
- **员工行数**：员工记录数量
- **月份列数**：月份列的数量

#### 3.2 导出内容
导出的 Excel 包含以下列：
- **项目名称**：项目标识
- **员工**：员工姓名
- **所属部门**：完整部门名称
- **部门简称**：部门简称
- **职位**：员工职位
- **月份列**：每个项目每月的工时（动态列）

### 使用方法

#### 导出操作
1. 点击"导出每项目工时"按钮
2. 系统自动生成 Excel 文件
3. 文件名格式：`每项目工时_Close口径_YYYYMMDD.xlsx`

#### 数据说明
- **Close 口径**：只统计 `current_node = Close` 的记录
- **连续月份**：从最早到最晚的连续月份
- **默认全部**：导出所有项目，不做筛选

## 📝 4. 完整填报率 - 工时填报差异分析

### 功能介绍
查看员工工时填报与目标值的差异情况。

### 主要内容

#### 4.1 差异统计
- **应填报工时**：目标值（默认 40h/周期）
- **实际工时**：员工填报的工时
- **差额**：应填 - 实际
  - **差额 > 0**：少填（红色）
  - **差额 < 0**：超填（蓝色）

#### 4.2 部门汇总
- 按部门分组显示
- 显示每个部门的总差额
- 可展开查看部门内员工详情

### 使用方法

#### 筛选条件
- **年份**：选择年份（必选）
- **月份**：选择月份（可选）
- **周**：选择周（可选）
- **目标工时**：设置目标值（默认 40h）

#### 操作按钮
- **导出 Excel**：导出当前筛选条件下的差异数据
- **部门展开/收起**：查看部门内员工详情

#### 数据说明
- **排除未提交**：不统计 `approval_status = 未提交` 的记录
- **按周期聚合**：根据筛选粒度（周/月/季）聚合工时

## ✅ 5. 审批完成率 - 待审批工时汇总

### 功能介绍
查看当前待审批的工时记录汇总。

### 主要内容

#### 5.1 待审批统计
- **待审条数**：待审批的记录数量
- **待审工时**：待审批的总工时
- **未操作者**：当前待审批人

#### 5.2 待审批列表
- **部门**：员工所属部门
- **未操作者**：待审批人
- **待审条数**：该待审批人的记录数量
- **待审工时**：该待审批人的总工时

### 使用方法

#### 筛选条件
- **年份**：选择年份（必选）
- **月份**：选择月份（可选）
- **项目筛选**：多选项目（可选）
- **未操作者筛选**：单选待审批人（可选）

#### 操作按钮
- **导出 Excel**：导出当前筛选条件下的待审批数据

#### 数据说明
- **排除已完成**：不统计 `current_node = Close` 的记录
- **排除准备中**：不统计 `current_node = Prepare` 的记录
- **按待审批人分组**：统计每个待审批人的待审条数和工时

## 📤 6. 上传工时 Excel

### 功能介绍
上传工时 Excel 文件，系统自动解析并保存到数据库。

### 使用方法

#### 上传步骤
1. 点击右上角"上传 Excel"按钮
2. 选择工时 Excel 文件
3. 系统自动解析并显示处理结果

#### Excel 文件格式要求

**必填列**（必须存在）：
- `员工`：员工姓名
- `所属部门`：部门名称
- `工号`：员工工号
- `开始日期`：工时开始日期
- `结束日期`：工时结束日期

**业务列**（可选）：
- `项目名称(新)`：新项目名称（优先使用）
- `项目名称(作废)`：旧项目名称（备选）
- `非项目名称`：非项目工时名称
- `合计`：工时数值（系统会自动区分项目和非项目）
- `任务详情`：任务描述
- `核准状态`：审批状态
- `当前节点`：流程节点
- `未操作者`：待审批人

**部门简称映射**：
- 系统会自动将部门名称映射为简称
- 例如：`110.1 R&D - Digital` → `Digital`
- 可通过 `部门简��.xlsx` 文件自定义映射

#### 数据处理规则

**项目归属**：
1. 优先使用 `项目名称(新)`
2. 若为空，使用 `项目名称(作废)`
3. 若仍为空，使用 `非项目名称`
4. 三者都无，该行跳过

**分类规则**：
- 项目名称 → `category = Project`
- 非项目名称 → `category = Non-Project`

**跳过规则**：
- 员工为空
- 工时为空或 0
- 日期无法解析

**Close 口径**：
- 主看板只统计 `current_node = Close` 的记录
- 即：已完成审批的工时

## 📊 8. 数据统计口径说明

### 8.1 Close 口径
**定义**：只统计 `current_node = Close` 的工时记录

**说明**：
- `Close` 表示已完成审批
- 这是主看板的统计口径
- 确保只统计已确认的工时

### 8.2 排除未提交
**定义**：排除 `approval_status = 未提交` 的记录

**说明**：
- 未提交的记录不计入填报率
- 只统计已提交的工时

### 8.3 排除准备中
**定义**：排除 `current_node = Prepare` 的记录

**说明**：
- `Prepare` 表示准备阶段
- 不进入待审批统计

## 🐛 10. 常见问题

### 10.1 数据相关

**Q：为什么总工时和我手算的不一样？**
A：系统使用 `Close` 口径统计，只计算已完成审批的工时。请确认筛选条件和统计口径。

**Q：上传 Excel 后数据没有变化？**
A：请检查：
1. Excel 文件格式是否正确
2. 必填列是否都存在
3. 日期格式是否正确
4. 查看上传后的处理结果提示

**Q：部门名称显示不正确？**
A：系统会自动映射部门简称。如需修改，请提供 `部门简称.xlsx` 文件。

### 10.2 界面相关

**Q：页面加载很慢？**
A：请检查：
1. 网络连接是否正常
2. 浏览器是否缓存了旧版本（尝试 Ctrl+Shift+R 强制刷新）
3. Hugging Face 服务是否正常

**Q：筛选器不显示？**
A：请检查：
1. 是否已上传工时数据
2. 数据中是否有对应的部门/项目
3. 尝试刷新页面

### 10.3 上传相关

**Q：上传失败？**
A：请检查：
1. 文件格式是否为 `.xlsx` 或 `.xls`
2. 文件是否损坏
3. 文件大小是否过大（建议 < 10MB）

**Q：如何查看上传结果？**
A：上传成功后，系统会显示处理结果，包括：
- 处理的行数
- 成功/失败状态

## 📚 附录

### A. 业务术语表

| 术语 | 说明 |
|------|------|
| Close | 已完成审批，可进入统计 |
| Prepare | 准备阶段，不进入统计 |
| BU | Business Unit，业务单元 |
| PRD | Product Requirements Document，产品需求文档 |
| RTL | Register Transfer Level，寄存器传输级 |
| Tape out | 流片，芯片制造 |
| Fab out | 制造完成 |
| Silicon | 硅片 |
| ATE | Automatic Test Equipment，自动测试设备 |
| CS | Customer Ship，客户发货 |
| RTP | Release to Production，量产发布 |

### B. 数据字典

**TimeEntry（工时记录）**：
- `employee_name`：员工姓名
- `employee_id`：员工工号
- `department`：部门简称
- `department_full`：部门全称
- `position`：职位
- `project_name`：项目名称
- `category`：分类（Project/Non-Project）
- `start_date`：开始日期
- `end_date`：结束日期
- `hours`：工时
- `task_details`：任务详情
- `approval_status`：核准状态
- `current_node`：当前节点
- `pending_approver`：待审批人

**ProjectSchedule（项目进度）**：
- `project_name`：项目名称
- `bu`：业务单元
- `status`：项目状态
- `planned_days`：计划周期
- `actual_days`：实际周期
- `delta_days`：差异天数

**Milestone（里程碑）**：
- `name`：里程碑名称
- `planned_date`：计划日期
- `actual_date`：实际日期
- `delta_days`：差异天数
