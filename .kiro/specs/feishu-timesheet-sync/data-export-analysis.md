# 网站数据导出功能与飞书新需求的关联分析

## 网站现有数据导出功能

### 1. 定制化数据导出（Custom Data Export）
**功能**: 按项目导出每位员工的月度工时数据
- **数据范围**: 仅包含 `category = "Project"` 且 `current_node = "Close"` 的记录
- **导出格式**: Excel宽表，按项目和员工分组，按月份展开
- **导出字段**: 项目、员工、所属部门、部门简称、职位、各月工时、总计
- **数据来源**: 从后端 `/api/time-entries` 获取

### 2. 人月占比导出（Person-Month Ratio Export）
**功能**: 计算每位员工每月在各项目的工时占比
- **计算规则**: 
  - 仅统计 `current_node = "Close"` 的记录
  - 项目工时计入总工时
  - 非项目工时中只有 management、others、training 计入总工时
  - Public Holiday 和 Timeoff 不计入总工时
- **导出格式**: 按项目、员工、月份的占比数据

### 3. 审批状态导出（Approval Export）
**功能**: 导出待审批的工时记录
- **导出字段**: 部门、待审批数量、总工时

### 4. 填报状态导出（Reporting Export）
**功能**: 导出各部门的填报情况
- **导出字段**: 周期、部门、应填报工时、实际工时、差额

## 飞书新需求分析

### 新增的关键需求
1. **需求29**: 项目和项目经理配置 - PM配置项目与PL的对应关系
2. **需求30**: 非项目工时分类 - 定义5种非项目工时类型
3. **需求31**: 标准工时配置 - HR/财务提供的标准工时数据

## 关联分析

### 1. 数据流向关联

```
飞书工时填报
    ↓
工时数据存储（TimeEntry表）
    ↓
后端计算和统计
    ↓
网站数据导出
```

### 2. 需求与导出功能的关联

#### 需求29（项目配置）与导出的关联
- **当前状态**: 网站导出中的"项目"字段直接来自 `project_name`
- **新需求影响**: 
  - 项目名称现在由PM配置和维护
  - 导出时需要验证项目名称的有效性
  - 可能需要添加项目经理（PL）信息到导出数据中
- **建议**: 在导出数据中添加"项目经理"列，便于追踪审批人

#### 需求30（非项目工时分类）与导出的关联
- **当前状态**: 网站导出仅包含 `category = "Project"` 的数据
- **新需求影响**:
  - 非项目工时现在有明确的分类（Management、Others、Public Holiday、Timeoff、Training）
  - 人月占比计算已经区分了这些分类
  - 导出功能需要支持按非项目工时分类进行统计
- **建议**: 
  - 添加非项目工时分类导出功能
  - 在人月占比导出中明确显示各分类的工时占比

#### 需求31（标准工时配置）与导出的关联
- **当前状态**: 网站导出中没有显示标准工时信息
- **新需求影响**:
  - 标准工时由HR/财务提供，系统管理员配置
  - 导出数据应该包含标准工时，便于对比实际工时
  - 工时差异分析需要基于标准工时
- **建议**:
  - 在导出数据中添加"标准工时"列
  - 添加"工时差异"列（实际工时 - 标准工时）
  - 支持按标准工时进行工时异常预警

### 3. 数据一致性关联

#### 审批流程与导出的关联
- **当前状态**: 导出仅包含 `current_node = "Close"` 的已批准工时
- **新需求影响**:
  - 审批流程现在包括部门负责人 → PL → PM的多级审批
  - 导出时需要确保只导出所有审批级别都通过的工时
  - 需要追踪审批链路
- **建议**:
  - 在导出数据中添加"审批状态"列
  - 添加"审批人"列（部门负责人、PL）
  - 支持按审批状态进行筛选导出

#### 非项目工时分类与人月占比的关联
- **当前状态**: 人月占比计算中已经区分了非项目工时分类
- **新需求影响**:
  - 需要确保导出的人月占比与系统计算规则一致
  - 需要在导出中明确显示各分类的计算方式
- **建议**:
  - 在人月占比导出中添加"分类"列
  - 添加"是否计入人月占比"列
  - 提供详细的计算说明

## 建议的改进方案

### 1. 增强导出功能
- 添加"项目经理"列到定制化数据导出
- 添加"标准工时"和"工时差异"列
- 添加"审批状态"和"审批人"列
- 支持按非项目工时分类进行单独导出

### 2. 新增导出功能
- 非项目工时分类统计导出
- 审批流程追踪导出
- 工时异常预警导出（基于标准工时）

### 3. 数据验证
- 验证导出的项目名称与PM配置的项目一致
- 验证导出的非项目工时分类有效
- 验证导出的工时与标准工时的对应关系

### 4. 用户体验改进
- 提供导出前的数据预览
- 支持自定义导出字段
- 支持按多个维度进行筛选导出

## 总结

**网站数据导出功能与飞书新需求的关联**:

1. **项目配置需求** → 导出中需要添加项目经理信息
2. **非项目工时分类需求** → 导出中需要支持按分类统计
3. **标准工时配置需求** → 导出中需要添加标准工时和差异分析

这些改进将使网站的数据导出功能更加完整，能够更好地支持工时管理和分析。
